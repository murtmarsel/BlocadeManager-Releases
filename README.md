# Blocade Управление

[Скачать APK](https://github.com/murtmarsel/BlocadeManager-Releases/releases/tag/v0.1.0-preview)

Android 8+. Вход по email, паролю и коду из письма. Привязка устройства по QR с согласия пользователя.

Блокировка и разблокировка, сообщения и шаблоны, карта последней точки, батарея, GPS, яркость, даты и рабочее расписание. Требуются обновлённые сервер и клиент Blocade.

APK подписан постоянным ключом. Первый выпуск предварительный: проверка на физическом телефоне ещё не завершена. Исходники хранятся в отдельном приватном репозитории.
