# Blocade Управление

[Скачать APK](https://github.com/murtmarsel/BlocadeManager-Releases/releases/tag/v0.4.2-preview)

Android 8+. Единый вход по email, паролю и коду из письма. Роль определяется сервером.

Блокировка и разблокировка, сообщения и шаблоны, карта последней точки, батарея, GPS, яркость, даты и рабочее расписание. USB/OTG-мастер устанавливает встроенный Blocade, настраивает устройство и привязку, снимает управление и удаляет приложение только для администратора. Нужны подтверждение USB-отладки и интернет на обоих телефонах. Администратор автоматически получает самостоятельную Android-панель после входа. Требуются обновлённые сервер и клиент Blocade.

APK подписан постоянным ключом. Выпуск предварительный: проверка на физическом телефоне ещё не завершена. Исходники хранятся в отдельном приватном репозитории.
